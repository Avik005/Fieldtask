
# Support Queue – FieldTask

A mobile support-ticket management screen built using Expo, React Native and TypeScript.

## Features

- Support Desk header and agent label
- Dynamic unresolved and urgent ticket summaries
- Status-based filtering
- Assigned-to-me toggle
- Case-insensitive ticket search
- Ticket priority and waiting-time indicators
- Resolve ticket functionality
- Empty state and clear-all filters
- Priority-based ticket sorting

## Tech Stack

- Expo
- React Native
- TypeScript

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Start the Expo development server

```bash
npx expo start
```

### 3. Run the application

- Press `a` to open the Android emulator.
- Alternatively, scan the QR code using Expo Go on your Android device.
